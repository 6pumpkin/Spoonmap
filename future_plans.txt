================================================================================
                    SPOONMAP 향후 핵심 기능 로드맵 (Future Plans)
================================================================================

[ 테마 1 ] 📱 모바일 앱화 (PWA) & 모바일 특화 경험
--------------------------------------------------------------------------------
1. 홈 화면 앱 설치 (PWA, Progressive Web App)
   - 스마트폰(아이폰 Safari, 갤럭시 Chrome)에서 "홈 화면에 추가" 시 앱스토어 설치 없이 네이티브 앱처럼 동작
   - 브라우저 상단 주소창 및 하단 네비게이션 바가 사라지고 독립된 전체화면(Full Screen) 구동
   - 전용 앱 아이콘, 스플래시(로딩) 화면, 오프라인 캐싱 지원

2. 모바일 한 손 조작 바텀 시트 (Bottom Sheet)
   - 스마트폰에서 다이어리 작성 및 식당 상세 정보를 열 때 화면 아래에서 부드럽게 올라오는 바텀 시트 UI
   - 아래로 스와이프하여 닫기 제스처 지원


[ 테마 2 ] 🧠 미식 인텔리전스 (AI 영수증 OCR & 스마트 내비게이션)
--------------------------------------------------------------------------------
1. 영수증 OCR AI 자동 판독 및 자동 입력
   - 결제 후 영수증 사진을 찍어 올리면 AI가 식당명, 방문 일시, 주문 메뉴, 결제 금액을 자동 추출
   - 다이어리 입력란에 1초 만에 자동 채워주어 번거로운 텍스트 입력 최소화

2. 원클릭 길찾기 & 실시간 내비게이션 앱 연동
   - 식당 상세 모달 및 지도 탭에서 클릭 한 번으로 모바일 내비게이션 앱 자동 실행
   - 카카오내비, 네이버지도 앱, TMAP과 즉시 연동되어 목적지 길안내 시작


[ 테마 3 ] 💬 카카오톡 공유 & 소셜 미식 네트워크
--------------------------------------------------------------------------------
1. 카카오톡 맛집 카드 1초 공유
   - 내가 다녀온 맛집이나 추천 코스를 카카오톡 메시지 카드(썸네일 사진, 수저 평점, 주소, 카카오맵 링크 포함) 형태로 친구에게 바로 전송

2. 내 맛집 지도 & 위시리스트 공유 링크
   - 내가 모은 식당 리스트와 다이어리를 고유 웹 링크(URL)로 친구나 지인에게 전달하여 바로 조회 가능

3. 카카오 장소 검색 API 자동완성
   - 새 식당 등록 시 식당명만 입력하면 카카오 장소 검색 API를 통해 도로명 주소, 좌표(위/경도), 공식 카카오 Place ID가 100% 오타 없이 자동 매칭

4. 친구 지도 겹쳐보기 & 소셜 미식 피드
   - 팔로우한 다른 미식가 유저들의 최근 방문 기록을 타임라인 피드로 확인
   - 친구의 저장 맛집 마커를 내 지도 위에 레이어로 겹쳐보며 새로운 맛집 함께 탐색

5. 전체 미식가 통합 '또간집 명예의 전당' 랭킹
   - Spoonmap을 사용하는 모든 사람들의 방문 통계를 종합하여 지역별/카테고리별 최다 재방문 랭킹 탭 제공


[ 테마 4 ] 📊 연말 미식 결산 (Spoonmap Wrapped)
--------------------------------------------------------------------------------
1. 스포티파이 랩드(Spotify Wrapped) 스타일 인포그래픽 리포트
   - 1년(또는 특정 기간) 동안의 방문 기록을 분석하여 시각화 리포트 자동 생성
   - "올해 나의 또간집 TOP 3", "내가 가장 사랑한 메뉴/카테고리", "최다 방문 지역", "총 방문 횟수" 등을 잡지/카드 뉴스 스타일 그래픽으로 렌더링

2. SNS 및 메신저 공유 카드 내보내기
   - 인스타그램 스토리, 카카오톡 등에 최적화된 고화질 카드 이미지로 1초 만에 저장 및 공유


[ 테마 5 ] 📈 데이터 관리 & 미식 분석 고도화
--------------------------------------------------------------------------------
1. 다이어리 엑셀/CSV 양방향 동기화
   - 현재 CSV 내보내기 외에, 엑셀 파일 업로드를 통한 일괄 등록/복원 기능 제공

2. 지출 금액 통계 및 월별 외식비 분석
   - 방문 기록별 지출 금액 입력 시 월별 외식 지출 추이, 카테고리별 소비 비중 그래프 제공

3. 미식 코스 큐레이션 (1차 ➔ 2차 연계 코스)
   - 1차 식당(식사)과 2차 카페/술집을 묶어서 하나의 '미식 코스'로 저장하고 추천하는 기능
